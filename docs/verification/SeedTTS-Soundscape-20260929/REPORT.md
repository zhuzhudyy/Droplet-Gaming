第一轮激光／金属使用英语 Tim 与中文描述，没有得到有效音频；不能由此推断模型整体能力。其余中文样例采用官方 HTTP 示例的 `zh_female_vv_uranus_bigtts`，已得到完整输出，解决的是文本／音色试验条件，不是内容验收。

**主观试听：未执行。** 本会话工具不支持音频感知输入。使用本机已安装 Microsoft Speech Recognizer 8.0 / zh-CN 对录音文件做第一句自由听写，没有上传音频、使用麦克风、强制原文语法或安装服务。完整描述句的还原提供提示词朗读的辅助证据；短音节、低置信度或空结果均可能误判，不能证明真实物体音色、无旁白、自然度、失真或循环合格。不把 ASR 置信度当作准确率，也不把本次失败扩大为 Seed-TTS 所有可能提示词都不支持非语音的结论。

证据：[当前自由听写](offline-speech-inspection.json)，此前两次结果 `speech-inspection-*.json` 原样保留。音频全在 Assets 外，未经过调音、裁切、循环或混合。处理配方仅为服务 PCM 无损封装成 WAV；没有替代声源。
