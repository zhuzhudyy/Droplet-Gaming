# v0.2.2 原生窗口交互

最终benchmark结束后已恢复正常Mission/Input组件，回到Ready。在同一实际Windows玩家窗口中用原生鼠标自动化点击BEGIN SORTIE，观察PLAYING；随后正常帧运动贯穿前方四艘，看到4/40、1000分、速度24。截图v0.2.2-native-playing.png。

原生注入Escape没有在随后的截图中产生暂停，仍不能把它标为物理键盘验证通过。接着正常激活已有Unity Editor窗口，再激活玩家窗口，观察因失焦触发PAUSED，计时显示03:28，4/40、1000分。截图v0.2.2-native-paused.png。没有强制关闭程序、写注册表或改变输入后端。

点击暂停页RESTART，实际显示READY、04:00、0/40、00000分、速度24；模型舰队恢复，光效清理。截图v0.2.2-native-restarted.png。最终独立程序留在Ready供用户试玩；Unity保持已保存FleetAssault且退出Play。

这是实际按钮/失焦/运动观测，补充独立自动路线及Unity测试，不代表主观鼠标手感、真实键盘或音效听感验收。
