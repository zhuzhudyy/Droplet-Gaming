# Seed Audio 离线素材验收

本文件说明 131 条非语音目录素材的**客观**检查方式。检查脚本不连接服务、不生成音频、不改动原始、暂存或发布 WAV。六类代表样音已获用户听感认可；目录内的独立变体与 87 条新版对白仍需分别试听，数值检查不代表内容、表演或游戏内混音通过。

## 重扫与试听

在项目根目录运行：

```powershell
python -B Tools/Audio/seed_catalog_qa.py
python -B Tools/Audio/seed_delivery_qa.py
python -B Tools/Audio/seed_voice_qa.py
```

各脚本只写自己的报告和试听索引：

- `ArtSource/Audio/SeedAudio20260929/catalog-qa/summary.json` 与 `listening.html`：Seed 原始非语音 WAV；
- 同目录 `delivery-summary.json` 与 `delivery-listening.html`：处理后暂存/发布 WAV，可在同一行对照原声；
- `ArtSource/Audio/SeedAudio20260929/voice-qa/summary.json` 与 `listening.html`：87 条新版英语干声及中文字幕文本。

生成进程运行时，`submission_unknown` 只显示为 `in_flight_or_unresolved`，不得凭该状态断言失败或自动重发。当前替代来源 `Laser_03 → Laser_03_R2` 由 catalog 的 `sourceId` 明确指定；原 502 任务记录仍保留，QA 以正式 Cue ID 显示而从替代来源读取 WAV、请求与哈希。

## 检查范围

原声层逐条确认 131 个正式 ID / 来源 ID 唯一，完整请求与提示词、SHA-256、48 kHz PCM16、声道、实际时长、静音与近满幅样本。对生成前后尚未完成的项目按状态单独计数。处理层核对暂存候选的来源 SHA、版本化身份、输出 SHA、处理配方与 WAV 帧数；发布侧再核对同一 WAV 与 JSON 侧车的模型、提示词、来源、配方和技术指标。任何哈希或来源不一致属于技术问题。

对处理后循环，计算末样本到首样本的幅度跳变、该跳变与邻近正常采样差分 99 百分位的比值，以及首尾 250 ms 电平差。大于 0.05 且差分比值大于 8 的接缝列为错误；大于 0.01 且比值大于 5 或首尾电平差大于 9 dB 列为警告。一次性音效检查起音、尾音静音及首尾跳变。处理后时长小于目标 75% 或超过目标 110% 加 0.1 秒列为错误；小于目标 90% 列为警告。循环因交叉淡化而略短于 Seed 原声属正常现象。

相同 WAV 的跨类别或同类别复用均列为独立性错误；形状归一化相关系数 ≥0.997 的近重复只作候选提示，不能据此判定听感相同。原声及成品两层均检视独立性。

通讯遮蔽代理指标用 87 条干声的 300–3400 Hz 能量下四分位值，与每段循环背景在相同频带的采样值相减，报告 `unmixedVoiceToBedMarginDb` 及达到 12 dB 文件级余量所需的示意背景压低量。低于 6 dB 提醒在 Unity 中核对通讯压低。此值**未应用 Unity 的总线音量、空间衰减、动态压低或同时播放层数**；它不能代替玩家内录音和对白可懂度试听，也不单独阻断发布。

2026-09-29 最终扫描：131/131 正式原声可试听，131/131 成品已技术暂发并由 Unity Editor 导入；两层均为 0 技术问题、0 近重复候选。成品有 25 项非阻断提醒，其中 22 项为文件级通讯余量代理、2 项连击声起音偏迟、1 项滑条声偏短。`Laser_03` 正确映射 R2。六类代表已获用户试听认可，其余 131 单条变体尚未逐条听感验收。最终玩家检查见 [验收记录](../../SEED_AUDIO_ACCEPTANCE.md)。
