## 尺度契约

唯一权威配置：`Tools/Blender/SolarSystemLayout/layout_config.json`。固定相位圆轨道是游戏选择，不是真实星历；宏观以太阳为原点，单位AU、双精度。局部以现有舰队中心(0,20,260)为BattleAnchor映射点，1 Unity unit=1米。默认战区2.5 AU，固定相位230°、倾角2°。其余行星只做宏观编辑示意标记。

宏观轨道半长轴采用用户给定近似值，主带设计包络2.1–3.3 AU且有倾角/节点分布。局部岩石是人为选择的稀疏战区布景，不能据其数量推算整个主带密度。宏观分布标记不导出为实机岩石。

太阳/地球半径分别695700/6371 km。观察者位置先用double宏观数据减去天体位置，再转为受控三维代理。球代理半径=Dproxy×真实半径/真实距离，角直径2asin(r/d)；可读性倍率独立且默认1。代理近层14000米、范围4000米，天空壳22000米、far25000米，均独立于实际5840米边界。无原点重定位。
