本批 25 个非语音源效果是原创程序合成：激光、反射、撞击、爆炸、脚步、控制台、门机构各 3 个有效不同变体，加警报、设备振动、接通/断线各 1 条。脚步使用分开的脚跟/脚尖脉冲激励多个钢甲板振动模态、非等距步点和远去包络，**没有用白噪声代替脚步**。撞击/爆炸可使用带限瞬态激励，保留起音和衰减。原始参数、种子和来源在 `effects-manifest.json`。它们是程序声效，不能冒充真实船舱录音；复杂人物奔跑、衣物及拥挤人群的自然度尚未获得主观验收。

## 混音与本地工具

`Tools/Audio/cinematic_audio.py` 是确定性生成与 FFmpeg 编排入口；`cinematic_audio_qa.py` 复核实际文件并发布 READY。FFmpeg 9.0.1、Python 3.14.3。主角电平与背景人物分别整定，保持远近差；动作/舱室经短房间反射，随后 `atrim/asetpts/adelay` 对齐、`volume/afade` 包络、`amix normalize=0 dropout_transition=0` 固定增益合成，`sidechaincompress` 给对白让位。所有舱内层统一经过 230–4,300 Hz 通讯总线、轻压缩和受控软限幅，最后才加接收端接通/断线。没有把背景当直接贴在玩家耳边的全频声。原生 24 kHz PCM 保留，不把格式转换说成升质。

Audacity 已安装，但当前没有可用的脚本自动化连接；全部制作由 FFmpeg 实际执行，可凭配方复现。**没有操作 Audacity，没有声称保存其工程。** 听觉/情绪感知不可由本代理完成，所以“已生成、已混音、信号检查通过”与“已试听”分开。

## 游戏调度

复用 `FleetCombatSimulation.EventRaised`。`BattleAudioDirector` 根据近 8 秒、0.25 秒分桶的真实附近开火/接触/贯穿/爆炸/撤离事件，计算有升降平滑的强度；8 秒外无事件贡献，之后平滑衰退。强度选择低/中/高预混、广播间隔（稀疏到紧凑）、世界音效并发 5–12 和事件权重。只读 Intensity、DensityState、ActiveWorldSources、ReceivedEvents、PlayedWorldEvents、DroppedWorldEvents 供实际运行验证。

广播只选一个完整预混，不同时播放原轨；最多一条主通讯，预混背景人物不超过一个同时回应。4 条有界队列、3.5 秒过期、稳定事件 ID 去重、来源舰 ID/代际校验、状态过滤和冷却抑制过时求救。待爆剩余不足 3.3 秒时使用 HELP 短版，真实爆炸仍会立即停止整个舱内混音和其他舱内辅助音源，只留下 0.2 秒接收端断线。没有改伤害、得分或爆炸期限。

世界开火/接触分别取 WeaponFired/DropletContact，旧 LaserReflected 只负责广播，避免一击双播。世界音源池最多 12，远处密集开火可被预算舍弃；每个来源/时间都来自真实事件。事件位置按记录的原点偏移重定位。旧 MissionEffects/LaserBeamPool 世界声在**新场景**关闭，飞行声保留。特写只对已经播放且 eventId 匹配的音源做 12% 短强调，绝不重播事件；唯一听点由根集成维持在正常战斗听点。

暂停冻结音源与调度时基；剧情跳过、结算和重开清掉队列、强度、舱内层、池和去重缓存。字幕来自逐句真实音频起止，SE01 包含主角/背景/第二句主角三条字幕。新 Timeline 每槽与实际 AudioClip.length 同步。
